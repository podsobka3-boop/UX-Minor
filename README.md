# Делаешь?

Напоминалка о цели сессии за компьютером: записываешь, зачем сел за компьютер, а приложение в случайный момент спрашивает «Делаешь „…“?». Отвечать можно прямо кнопками в системном уведомлении.

Описание: [PRD.md](PRD.md), дизайн: [DESIGN.md](DESIGN.md), скриншоты: [docs/screenshots](docs/screenshots).

## Запуск

Нужен Node.js (LTS) с https://nodejs.org. В папке проекта:

```
npm install
npm run dev
```

На Windows приложение сразу откроется отдельным окном (Microsoft Edge в режиме приложения). На других системах — во вкладке браузера по адресу http://127.0.0.1:5173. Окно терминала с `npm run dev` не закрывайте, пока пользуетесь приложением.

Лучше всего работает в Edge или Chrome: там у системных уведомлений есть кнопки «Делаю» / «Отвлёкся».

## Как быстро посмотреть сценарий

1. Нажмите «Включить» на плашке уведомлений и разрешите их.
2. Включите «Демо-режим»: вопросы будут приходить через 5–15 секунд, а не через 5–20 минут.
3. Введите цель, нажмите «Начать» и переключитесь в другое окно — придёт уведомление.
4. Вернитесь, нажмите «Сделал!» → «Да, всё» → увидите итог. Сессия появится в «Истории».

Если уведомление попадает в Центр уведомлений Windows, но баннер не всплывает, в приложении есть подсказка «Не видишь баннер?».

Данные хранятся в localStorage этого браузера и сохраняются после перезагрузки.
